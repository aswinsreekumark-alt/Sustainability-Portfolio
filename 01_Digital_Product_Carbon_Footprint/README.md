# Digital Product Carbon Footprint & BOM-to-PCF Automation

An illustrative cradle-to-gate Product Carbon Footprint assessment of a 5.5 kW industrial three-phase induction motor.

This project demonstrates BOM data cleaning, environmental dataset mapping, life cycle modelling in openLCA, electricity sensitivity analysis, and Power BI visualisation.

**Project status:** Demonstration model using simulated BOM data and illustrative manufacturing assumptions.
